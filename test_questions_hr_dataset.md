## 📝 Notes for Testing

- Questions are ordered from simple to complex within each category
- Each WHY question should generate 3 testable hypotheses
- Expect Chi-square tests for categorical relationships
- Expect t-tests/ANOVA for categorical vs numerical
- Expect correlation tests for numerical vs numerical
- Visualizations should match question type (bar, pie, scatter, histogram, etc.)
- Simulation questions should return predicted attrition % change with confidence ranges
- Multi-factor simulation questions should show individual vs combined effect sizes
