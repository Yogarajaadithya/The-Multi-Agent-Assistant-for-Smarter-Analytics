## 📝 Notes for Testing

- Questions cover all 28 columns in the dataset
- Each WHY question should generate 3 testable hypotheses
- Expect Chi-square tests for categorical relationships (channel vs segment, category vs status)
- Expect t-tests/ANOVA for categorical vs numerical (segment vs revenue, category vs price)
- Expect correlation tests for numerical vs numerical (price vs quantity, discount vs profit)
- Visualizations should match question type:
  - Bar charts for category comparisons
  - Pie charts for distribution/proportions
  - Line charts for temporal trends
  - Scatter plots for relationships
  - Heatmaps for multi-dimensional analysis
