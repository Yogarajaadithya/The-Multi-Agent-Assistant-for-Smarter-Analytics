# Database Utility Scripts

This folder contains utility scripts for database management and data loading.

## Scripts

- **check_schemas.py** - Check existing schemas and tables in PostgreSQL
- **list_databases.py** - List all available databases
- **setup_multi_dataset_schemas.py** - Initialize schemas for multiple datasets
- **create_schema_and_upload.py** - Create schema and upload data
- **load_to_postgres.py** - Generic data loading script
- **upload_sales_data.py** - Upload sales data to PostgreSQL

## Usage

Run scripts from the backend-repo directory:
```bash
python scripts/check_schemas.py
```

These are maintenance/setup scripts and are not part of the main application.
